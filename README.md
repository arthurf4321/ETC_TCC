# Sistema de Gestão de Pedidos - Loja de Açaí

Este é um sistema desenvolvido para otimizar a gestão de pedidos e a comunicação entre os funcionários em uma loja de açaí.  
O projeto foi desenvolvido como parte do Trabalho de Conclusão de Curso (TCC) na Escola Técnica de Ceilândia.

## Tecnologias Utilizadas

### Front-end

- **HTML** — Utilizado para estruturar as páginas do sistema.
- **CSS** — Responsável pela estilização e design visual das páginas.
- **JavaScript** — Utilizado para realizar validações no lado do cliente, garantindo que os dados inseridos nos formulários sejam corretos antes de serem enviados ao servidor.
- **Bootstrap** — Utilizado para agilizar o desenvolvimento de um layout responsivo e moderno.
- **AdminLTE** — Utilizado como framework para o painel administrativo, oferecendo componentes prontos e um design profissional.

### Back-end

- **PHP** — Linguagem utilizada para desenvolver a lógica de negócio e a comunicação entre o sistema e o banco de dados.
- **MySQL** — Sistema de gerenciamento de banco de dados utilizado para armazenar informações como usuários, pedidos e status.

### Controle de Versão

- **Git** — Utilizado para controle de versões e gerenciamento das alterações no código-fonte do projeto.
